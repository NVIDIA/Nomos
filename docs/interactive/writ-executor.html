Executor rule

Council approval is necessary but not sufficient. The executor owns final local policy for the machine, sandbox, or remote infrastructure it controls.

Why This Boundary Matters

        
Different executor implementations can share the same contract while enforcing different local constraints.

      

      

        
Local machine
Runs beside an IDE or automation daemon with tightly scoped directories and tools.

        
Sandboxed worker
Turns each writ into an isolated container, VM, or job with bounded credentials.

        
Remote infrastructure
Maps writs to typed API operations instead of arbitrary shell execution.
