Fast Troubleshooting

        
Most first-run problems are environment, permissions, or missing credentials.

      

      

        

          
Council unhealthy

          
Check docker compose -f deploy/docker-compose.yml logs --tail=200 council. Missing config readability and missing API keys are the most common causes.

        

        

          
Executor rejects writ

          
The executor has its own policy. Verify working directory, allowed tools, denied paths, nonce state, and the X-Agent-ID header.

        

        

          
OPA denies request

          
The default profile requires absolute executable paths. Use /usr/bin/git rather than git, unless a specialized council explicitly relaxes that policy.
