Deployment Validation

        
Before debugging client payloads, prove the deployed monitor, council, and MCP contract are healthy.

      

      

        

          
Portable Kind or Compose checks

          
curl -fsS http://127.0.0.1:9901/healthz | python3 -m json.tool
curl -fsS http://127.0.0.1:9907/v1/health | python3 -m json.tool

uv run ./scripts/run_test_suite.py \
  --suite grpc-live \
  --suite mcp-live \
  --require-deployed

        

        

          
Low-risk live MCP council checks

          
set -a
. deploy/.env
set +a

NOMOS_MCP_LIVE_URL=http://127.0.0.1:9901/mcp \
NOMOS_AGENT_ID="$NOMOS_AGENT_ID" \
NOMOS_AUTH_TOKEN="$NOMOS_AUTH_TOKEN" \
uv run pytest \
  tests/test_mcp_live_integration.py::test_live_council_exposes_expected_tools_and_key \
  tests/test_mcp_live_integration.py::test_live_council_fails_closed_for_invalid_auth \
  tests/test_mcp_live_integration.py::test_live_council_mints_and_indexes_low_risk_writ \
  -q

Tool Selection Rules

        
Use these as client integration defaults.

      

      

        
NeedToolNotes

        
          
Run a command after approvalcouncil_authorize or council_v2_authorizeReturns a writ blob; submit it to the executor.

          
Ask “would this be approved?”council_propose_intentRuns policy and review but does not mint a writ.

          
Select a specialized councilcouncil_v2_authorizeRequires council_id and membership.

          
Verify executor trust rootcouncil_get_public_keyExecutors can also load the public key from a mounted file.
