Role Presets

        
Account CLI roles expand to permission scope sets (nomos/auth/permissions.py). A role says nothing about which councils the account may petition — that is the account's own councils set, written with --council (repeatable; omitting it grants --default-council only). A stored value of "*" in that set matches every council — it is a membership value an operator grants, not a property of the admin role.
