APF vs Nomos

An interactive comparison of the Agent Policy Fabric proposal against the Nomos implementation: where they align, where Nomos is stronger, and what would be required to make Nomos APF-compatible.

Bottom line

Nomos is a working governed execution kernel. APF is a broader governance fabric. Nomos can become an APF-compatible adapter or substrate, but it is not APF Core as-is.

APF Core

What Nomos can credibly claim today

Nomos can claim a governed execution path with signed, single-use execution authorization, independent executor verification, agent authentication, local runtime policy, and tamper-evident audit. It should not claim APF Core until durable signed policy authority and projection provenance exist.

Implementation Roadmap

The shortest path is to wrap Nomos' strong execution kernel with APF-compatible policy and audit contracts instead of replacing Nomos internals.

Define a signed policy bundle

Create a manifest over council config, OPA policy, executor profile, account policy metadata, projection digests, signer id, trust root id, expiry, revocation reference, and rollback counter.

Add a Runtime Policy Verifier layer

Expose APF-style verify, projection, authorization, and policy digest APIs. Initially route them into existing Nomos OPA, council, and executor policy components.

Recast existing config as projections

Treat Rego, MCP tool schemas, executor YAML, audit fields, and runtime policy as generated or verified projections from the signed bundle.

Thread policy provenance through Writs and evidence

Add policy digest, bundle version, signer id, and trust root id to Writs, executor evidence, ledger entries, and monitor summaries.

Add shrink-only detector verdicts

Let authenticated detectors reduce authorization for scoped TTL windows. Verdicts should never mint Writs, broaden permissions, or extend credential lifetime.

Publish a scoped conformance declaration

Declare Nomos as an APF-compatible privileged-execution adapter/substrate profile. Avoid claiming full APF or ODIS conformance until identity, delegation, credential proxy, and audit contracts are complete.
