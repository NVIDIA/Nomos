Pick your path

three integration shapes

A.1 — Agent identity

Each agent has an agent_id and a bearer token. In production these come from the admin API or a Vault path; the demo signup UI is dev-only.

What the agent stores in its environment:

  • NOMOS_AGENT_ID — your identifier.
  • NOMOS_AUTH_TOKEN — the agent token, sent inside tool arguments.
  • NOMOS_COUNCIL_URL — e.g. https://nomos.example.com/mcp.
  • NOMOS_EXECUTOR_URL — e.g. https://exec-prod.example.com.
  • MONITOR_MCP_PROXY_TOKEN — Bearer on the transport.

A.2 — Two credentials, two purposes

Transport (Bearer): the monitor's /mcp proxy token. Gates whether you can reach the council at all. One value per deployment.

Identity (auth_token): the agent's own token, sent inside each MCP tool's arguments. The council looks it up to know which agent is calling and what permissions to apply.

Executor binding (X-Agent-ID): sent on the executor call so it can verify the writ's target_agent_id matches.

A.3 — Working Python client

propose · poll · run · verify
"""Minimal Nomos agent client.
Submits an intent, polls until approval, runs the writ against the executor."""
import base64, json, os, time, uuid
import httpx
from trusted_executor_contract import ExecutionEvidence

COUNCIL_URL       = os.environ["NOMOS_COUNCIL_URL"]
EXECUTOR_URL      = os.environ["NOMOS_EXECUTOR_URL"]
AGENT_ID          = os.environ["NOMOS_AGENT_ID"]
AGENT_TOKEN       = os.environ["NOMOS_AUTH_TOKEN"]
MCP_PROXY_TOKEN   = os.environ["MONITOR_MCP_PROXY_TOKEN"]

def _mcp(client, name, **arguments):
    """One MCP tools/call. Returns the unwrapped `data` payload."""
    r = client.post(COUNCIL_URL,
        headers={"Authorization": f"Bearer {MCP_PROXY_TOKEN}",
                 "X-Council-Source": "my-agent"},
        json={"jsonrpc": "2.0", "id": str(uuid.uuid4()),
              "method": "tools/call",
              "params": {"name": name,
                         "arguments": {"auth_token": AGENT_TOKEN, **arguments}}},
        timeout=30)
    r.raise_for_status()
    parsed = json.loads(r.json()["result"]["content"][0]["text"])
    if not parsed["success"]:
        raise RuntimeError(parsed.get("error") or "tool failed")
    return parsed["data"]

def propose(client, **kw):
    return _mcp(client, "propose_intent", agent_id=AGENT_ID, **kw)["intent_id"]

def wait_for_approval(client, intent_id, deadline=60):
    started = time.monotonic()
    while True:
        s = _mcp(client, "check_proposal_status", intent_id=intent_id)
        if s["state"] in {"approved", "denied"}: return s
        if time.monotonic() - started > deadline:
            raise TimeoutError(f"still {s['state']}")
        time.sleep(1.0)

def run_writ(client, writ_blob):
    r = client.post(f"{EXECUTOR_URL}/v1/writs/execute",
        headers={"X-Agent-ID": AGENT_ID},
        json={"writ": writ_blob, "request_id": str(uuid.uuid4())},
        timeout=120)
    r.raise_for_status()
    return r.json()

def main():
    with httpx.Client() as client:
        intent_id = propose(client,
            description="Read the README",
            target_resource="/workspace/README.md",
            justification="Map repo before opening a PR",
            command="cat /workspace/README.md",
            working_directory="/workspace",
            blast_radius="Read-only",
            target_environment="development")
        status = wait_for_approval(client, intent_id)
        if status["state"] == "denied":
            return print("denied:", status.get("evaluation"))

        writ_blob = _mcp(client, "get_writ", intent_id=intent_id)["writ_blob"]
        result    = run_writ(client, writ_blob)

        ev = ExecutionEvidence(**result["evidence"])
        assert ev.verify(),       "executor evidence sig invalid"
        assert ev.payload.writ_id == result["writ_id"]
        print("stdout:", result["stdout"])

if __name__ == "__main__": main()

What this client gets right

  • Bearer on every council call — transport credential, monitor-level.
  • auth_token inside arguments — identity, council-level.
  • X-Agent-ID on executor call — binds caller to writ's target_agent_id.
  • Evidence sig + writ-id pin — proves the result wasn't fabricated by something between you and the executor.

Pin the executor fingerprint

When operators register a trusted executor, they get a stable Ed25519 fingerprint. Have the agent pin it in addition to verifying the signature:

expected_fp = os.environ["NOMOS_EXECUTOR_FINGERPRINT"]
assert ev.key_fingerprint == expected_fp,
       "unexpected executor identity"

B.1 — The HTTP contract

Three endpoints, all defined in trusted_executor_contract/models.py:

  • POST /v1/writs/execute — receive and run a writ.
  • GET /v1/health — liveness + capabilities + your fingerprint.
  • GET /.well-known/nomos/trusted-executor.json — machine-readable descriptor.

Caller MUST send X-Agent-ID: <id>. Your executor MUST reject if it doesn't match the writ's target_agent_id.

B.2 — Verification stages

These are non-negotiable. Skip any one and the security model breaks.

  • agent_binding · caller matches target_agent_id
  • signature · Ed25519 verify vs pinned council pub key
  • temporal · now ∈ [issued_at, expires_at]
  • nonce · atomic SET NX EX in a shared store
  • attachment · sha256 of each packaged file matches the writ field
  • command · your own local policy

B.3 — FastAPI skeleton

verify · run · sign evidence
"""Minimum-viable custom executor.
Translates a writ's `command` into a managed-service API call.
Replace `execute_business_logic` with your real implementation."""
import base64, hashlib, time, uuid
from contextlib import asynccontextmanager

import redis.asyncio as redis
from fastapi import FastAPI, Header
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from trusted_executor_contract import (
    AGENT_ID_HEADER, EXECUTE_ENDPOINT, HEALTH_ENDPOINT, WELL_KNOWN_ENDPOINT,
    ContractDescriptor, ExecuteWritRequest, ExecutedCommandEvidence,
    ExecutionEvidence, ExecutionEvidencePayload, ExecutionResult,
    ExecutionResultEvidence, ExecutorCapabilities, ExecutorHealth,
    WritOfExecution, validate_agent_binding,
)

# Trust anchor + identity loaded once at import.
COUNCIL_PUBLIC_KEY = open("/app/public-keys/council.pub", "rb").read()
IDENTITY_PRIVATE   = Ed25519PrivateKey.from_private_bytes(
    open("/app/executor-keys/executor.key", "rb").read())
IDENTITY_PUBLIC      = IDENTITY_PRIVATE.public_key().public_bytes_raw()
IDENTITY_FINGERPRINT = hashlib.sha256(IDENTITY_PUBLIC).hexdigest()
EXECUTOR_ID          = f"my-executor-{IDENTITY_FINGERPRINT[:16]}"
STARTED_AT           = time.monotonic()

@asynccontextmanager
async def lifespan(app):
    app.state.nonces = redis.from_url("redis://redis:6379/0", decode_responses=True)
    yield
    await app.state.nonces.aclose()

app = FastAPI(lifespan=lifespan)

@app.get(HEALTH_ENDPOINT)
async def health():
    return ExecutorHealth(executor_id=EXECUTOR_ID,
        key_fingerprint=IDENTITY_FINGERPRINT,
        uptime_seconds=time.monotonic() - STARTED_AT,
        capabilities=ExecutorCapabilities(execution_modes=["custom-api"],
            supports_packaged_files=False,
            metadata={"backend": "your-managed-service"}))

@app.get(WELL_KNOWN_ENDPOINT)
async def well_known(): return ContractDescriptor()

@app.post(EXECUTE_ENDPOINT)
async def execute(body: ExecuteWritRequest,
                  x_agent_id: str = Header(None, alias=AGENT_ID_HEADER)):
    # 1. Agent binding (cheap; fail fast before sig verify).
    fail = validate_agent_binding(body.writ, x_agent_id or "")
    if fail is not None: return fail

    writ = WritOfExecution.model_validate_json(base64.b64decode(body.writ))

    # 2. Signature.
    if not writ.verify(COUNCIL_PUBLIC_KEY):
        return ExecutionResult(writ_id=writ.writ_id, success=False,
            error="council signature invalid", verification_stage="signature")

    # 3. Temporal.
    now = time.time()
    if now < writ.issued_at or now > writ.expires_at:
        return ExecutionResult(writ_id=writ.writ_id, success=False,
            error="outside temporal window", verification_stage="temporal")

    # 4. Nonce — atomic SET NX EX is sufficient.
    claimed = await app.state.nonces.set(f"nomos:nonces:{writ.nonce}",
        writ.writ_id, nx=True, ex=int(writ.expires_at - now + 60))
    if not claimed:
        return ExecutionResult(writ_id=writ.writ_id, success=False,
            error="nonce already used", verification_stage="nonce")

    # 5. Your local policy + business logic.
    started = time.monotonic()
    try:
        outcome = await execute_business_logic(writ)
    except Exception as exc:
        return ExecutionResult(writ_id=writ.writ_id, success=False,
            error=str(exc), verification_stage="execution")
    duration = time.monotonic() - started

    # 6. Sign evidence — so the council can treat this as certified.
    payload = ExecutionEvidencePayload(
        executor_id=EXECUTOR_ID,
        executor_key_fingerprint=IDENTITY_FINGERPRINT,
        writ_id=writ.writ_id, intent_hash=writ.intent_hash,
        council_id=writ.council_id, writ_signature=writ.signature,
        target_agent_id=writ.target_agent_id, nonce=writ.nonce,
        command=ExecutedCommandEvidence(command=writ.command,
            working_directory=writ.working_directory),
        result=ExecutionResultEvidence(success=True,
            exit_code=outcome.get("exit_code", 0),
            stdout_sha256=hashlib.sha256(outcome.get("stdout", "").encode()).hexdigest(),
            stderr_sha256=hashlib.sha256(outcome.get("stderr", "").encode()).hexdigest(),
            duration_seconds=duration, verification_stage="passed"),
        request_id=body.request_id or str(uuid.uuid4()),
        signed_at=time.time())
    sig = IDENTITY_PRIVATE.sign(payload.canonical_bytes()).hex()

    return ExecutionResult(writ_id=writ.writ_id, executor_id=EXECUTOR_ID,
        success=True, exit_code=outcome.get("exit_code", 0),
        stdout=outcome.get("stdout", ""), stderr=outcome.get("stderr", ""),
        duration_seconds=duration, verification_stage="passed",
        evidence=ExecutionEvidence(public_key_hex=IDENTITY_PUBLIC.hex(),
            key_fingerprint=IDENTITY_FINGERPRINT, payload=payload, signature=sig))

async def execute_business_logic(writ: WritOfExecution) -> dict:
    # Replace with the real managed-service call:
    # e.g. boto3 ssm.send_command(…), kubectl exec, terraform run trigger.
    return {"exit_code": 0,
            "stdout": f"would have run: {writ.command}",
            "stderr": ""}

B.4 — Register as trusted

For the council to mark your evidence as certified, register your executor's public key in Redis at startup:

await app.state.nonces.hset(
  f"nomos:trusted_executors:{IDENTITY_FINGERPRINT}",
  mapping={"executor_id": EXECUTOR_ID,
           "public_key_hex": IDENTITY_PUBLIC.hex(),
           "key_fingerprint": IDENTITY_FINGERPRINT,
           "enabled": "1",
           "registered_at": str(int(time.time())),
           "updated_at": str(int(time.time())),
           "metadata_json": "{}"})
await app.state.nonces.sadd("nomos:trusted_executors",
                            IDENTITY_FINGERPRINT)

B.5 — Health & well-known

Always serve the well-known descriptor. It lets agent tooling auto-discover the execute endpoint and the headers it needs.

# advertised contract version & capabilities
curl -s https://my-exec.example.com/v1/health | jq

# machine-readable contract descriptor
curl -s https://my-exec.example.com\
   /.well-known/nomos/trusted-executor.json | jq

C.1 — The mixed flow

You run the shipped council unmodified. Your executors are custom because actions translate to managed-service calls. The agent:

  • Calls propose_intent on the council (Part A).
  • Polls check_proposal_status until approved.
  • Calls get_writ to retrieve the signed blob — does not call execute_intent.
  • POSTs {"writ": writ_blob, …} to your executor's /v1/writs/execute.
  • Verifies the executor's evidence signature.

C.2 — Why not execute_intent?

execute_intent assumes the council is responsible for running the writ — a pattern that fits co-located executors only. In the mixed case, the agent is the broker: it owns the decision of which executor instance receives the writ.

This is also how routing multi-region / per-tenant works. The same council can serve writs that one agent dispatches to exec-eu and another agent dispatches to exec-us.

C.3 — Recommended addition: report evidence

The shipped council records outcomes only when it ran execute_intent itself. In the mixed case, nobody updates the ledger automatically. After execution, have the agent call back to the council with a report_evidence(intent_id, evidence_blob) tool so the audit log stays complete. The exact tool name varies by version — check nomos/mcp/tools.py against your deployed council.

Cross-cutting concerns

things that bite later

Permissions

propose_intent succeeds only if the agent's role grants the relevant scope (shell:read, shell:write, file:read, …). New action classes need extending the scheme in nomos/auth/permissions.py.

Token rotation

Agent tokens are long-lived. Plan rotation via POST /api/admin/accounts/{id}/rotate-token. Reload from source-of-truth (Vault, K8s Secret) without restarting.

Idempotency

Council rejects duplicate intent_ids; generate a fresh one on retry. Executor is idempotent via the writ's nonce — second submission gets a nonce verification failure.

Observability

Always send X-Council-Source: <your-agent-name>. The monitor partitions metrics by source — cheapest way to tell "did our agent spike" from "is the council broken."

Verification ladder

end-to-end smoke
1. Authentication works

curl -s -H "Authorization: Bearer $MCP" $COUNCIL/debug/tools/list returns the tool catalog. 401 = wrong proxy token.

2. A low-risk intent gets approved

Run the Python client in Part A with command="echo hello". State transitions pending → approved within ~10s.

3. The executor accepts the writ

Response carries verification_stage: "passed" and a non-empty evidence block.

4. The evidence signature verifies

ExecutionEvidence(**result["evidence"]).verify() returns True. If false, your executor is mis-signing or returning corrupted bytes.

The two rules that keep this safe

  • The agent never bypasses the council. Direct calls to the executor without a valid writ should never originate from agent code.
  • The executor never trusts a writ it can't verify. All six verification stages, every time. The council signature is the entire authorization.

Closing

The council and the executor are stable, independent components separated by the writ. As long as your code respects that boundary, you can swap either side without touching the other.
