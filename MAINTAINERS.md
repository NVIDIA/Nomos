# Maintainers

Nomos is maintained by NVIDIA. Maintainer access is managed through the
NVIDIA GitHub organization rather than through a static list of individuals in
this repository.

## Responsibilities

Maintainers are responsible for:

- Reviewing and merging changes.
- Maintaining project documentation and required checks.
- Coordinating releases and release notes.
- Keeping licensing and third-party notices current.
- Routing security reports according to [SECURITY.md](SECURITY.md).

## Change Process

Changes must be submitted through pull requests, pass the repository's required
checks, and receive maintainer approval before being merged. Only authorized
maintainers may merge changes.

Nomos is currently not accepting external contributions. See
[CONTRIBUTING.md](CONTRIBUTING.md).

## Releases

When releases are published, maintainers create a version tag and use GitHub
Releases as the canonical release history. Before publishing, maintainers
verify that required documentation, license notices, and applicable release
checks are current.
