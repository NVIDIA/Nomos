## Collect and build on a machine that can reach Jev

Run from this directory in the updated `feat/context-format-pilot` checkout.
Supply `JEV_API_KEY` privately in the environment; never put its value in these
files, command arguments or recorded logs. Choose a fresh directory for each
collection. Do not reuse a failed or already-attempted directory.

```sh
RUN_DIR="$HOME/nomos-context-normal-path/v2-new-run"

# Offline: freeze exact inputs, source hashes and call order.
python3 benchmark.py --output "$RUN_DIR"

# One attempt per request; stops on the first failed assessment.
python3 benchmark.py --output "$RUN_DIR" --execute

# Independently reconcile all raw responses, hashes and durable attempt records.
python3 benchmark.py --output "$RUN_DIR" --summarize

# Separate figures; the original figures directory is protected from v2 writes.
uv run --no-project --with matplotlib==3.11.2 python plot_figures.py \
  --data "$RUN_DIR" --output figures-v2

# Separate report; v2 cannot overwrite the original report.html.
python3 build_report.py --data "$RUN_DIR" \
  --figures figures-v2 --output report-v2.html
```

Stop if any command fails. Preserve incomplete attempt records for diagnosis.
There are no automatic retries. Report generation requires a completed run;
its worked-example values, pending arguments, scores and summary come from the
selected frozen evidence, rather than v1's written example.

The HTML embeds exact requests and saved responses, so it can be read offline.
