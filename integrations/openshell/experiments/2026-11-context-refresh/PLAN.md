# Controlled rerun of the revised compact context

Frozen before new model calls. Reuse the 36 role-binding cases and 96
HTTP-decidable distraction cases and their existing captured HTTP/context
states. No case, label, outgoing HTTP field, original question, U prefix, model
or inclusive 0.70 threshold is changed. The current compact formatter changes
presentation, retained correlation fields and scope/limitations wording.

Four conditions:

| Key | Model input |
| --- | --- |
| original_context | Original questions and current compact context |
| guided_context | Same context; prepend the existing U paragraph to each question |
| without_council | Original questions and identical compact context except Council event reports are removed |
| http_only | Original questions and unchanged HTTP observation, without context |

The Council ablation removes only `nomos_council` objects. The scope stays the
same, describing any available Council reports without claiming one exists.
Use U on both cohorts; do not relabel the previous distraction study's C prefix.
Retain the original wording as reference. This tests reported evidence, not
live Council judgments, real Hermes actions, verified history or actual egress.

The existing captured states have no recorded timestamps. Reusing them isolates
the changed formatter and scope; it does not test timestamp effects. Do not
invent capture or execution times for historical fixture records.

Logical arm positions are near-balanced within cohort/expected-label strata
using shuffled cases and rotating four-arm Latin-square rows. Deduplicate exact
serialized requests globally; first occurrence determines actual call position.
Report actual counts rather than claiming balanced independent measurements
after deduplication. No salts, implicit retries or replacement of failed calls.

Prepare exact requests, source snapshots/hashes, matrix and call order offline.
Execute each distinct request once, serially, against `jev-1.14.0` with an
eight-second timeout. Persist started markers before I/O. Stop on an uncertain
or failed request; retain partial evidence. The API key is supplied only through
the environment and is never saved. Provider caching is unknown.

Report role pairs, role variants, the 12 role-study controls and the separate
96 distraction cases separately. Count harmful allows and false blocks, not
just aggregate accuracy. Council-specific benefit requires the Council ablation;
full-context versus HTTP-only measures all retained context. Historical changes
are descriptive, since model service variation and caching are uncontrolled.

If errors motivate another candidate, freeze it separately before its calls,
retain this run, and mark the next iteration as diagnostic development on seen
fixtures rather than independent validation. Do not tune the threshold or
claim general safety from small, related synthetic cases.
