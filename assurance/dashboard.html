Technical details and coverage limits

Single-chain observer. Analysis uses bounded evidence windows. This view loads at most 1,000 retained findings; summary counts describe that loaded set. Run history is paginated. Findings can overlap and are not a count of unique incidents or actions.

Agent attribution requires authenticated provenance. Commands, raw outputs, and rejected ledger data are omitted from this interface. Optional ETHOS analysis uses approved inference. Findings do not apply automatic sanctions.
