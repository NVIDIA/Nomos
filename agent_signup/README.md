# Nomos Agent Signup

`agent-signup` is a local bootstrap UI/API for creating Redis-backed Nomos
agent accounts. It is intentionally small:

- creates a new `agent_id`
- grants default council membership
- displays the council endpoint and one-time auth token
- provides a password-protected `/admin` backend for listing, editing,
  disabling, deleting, and rotating agent accounts

The public signup path is intentionally low-blast-radius and only creates roles
listed in `NOMOS_SIGNUP_ALLOWED_ROLES`. Use `/admin` or the CLI for privileged
account changes:

```bash
./scripts/agent_accounts.sh --help
```

The compose service publishes externally by default for remote deployments.
Keep the admin password strong and place the service behind production-grade
front-door authentication when exposing it outside a trusted network.

Useful environment variables:

- `AGENT_SIGNUP_PORT`: host port, default `9905`
- `AGENT_SIGNUP_BIND_ADDR`: host bind address, default `0.0.0.0`
- `NOMOS_SIGNUP_COUNCIL_ENDPOINT`: endpoint shown to users, default
  `http://${NOMOS_PUBLIC_HOST}:9901/mcp`
- `NOMOS_SIGNUP_COUNCIL_ID`: default council grant, default `council-prod`
- `NOMOS_SIGNUP_ALLOWED_COUNCILS`: comma-separated public signup council
  choices, default `council-prod`. Admins can update the live list from
  `/admin`; the public signup form only shows councils from this list.
- `NOMOS_SIGNUP_DEFAULT_ROLE`: default role, default `developer`
- `NOMOS_SIGNUP_ALLOWED_ROLES`: comma-separated HTTP-creatable roles, default
  `readonly,developer`
- `NOMOS_SIGNUP_ADMIN_USER`: `/admin` Basic auth username, default `admin`
- `NOMOS_SIGNUP_ADMIN_PASSWORD`: `/admin` Basic auth password; generated by
  `scripts/deploy_stack.sh` into `deploy/.env`
